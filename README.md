# tfcb_2026_demo
This repository holds my homework for TFCB 2026, including a wet lab experiment log and a tidy data exercise. It was made by Chan Mi ([chanmilee9496](https://github.com/chanmilee9496)).

## Collaborators 
Before the invitation, my collaborators could only view this repository. Now they have write access, so they can push commits, edit files, and manage issues. I still control the settings as the owner.

## Folder layout 
- `experiments/`: experiment logs, named by date and issue number
- `experiments/img/`: images referenced by the logs
- `analysis/qpcr/`: the tidy qPCR data exercise, with `data/` for input notes and `tables/` for output
